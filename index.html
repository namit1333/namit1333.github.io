02 / THE WAY I THINK

Curious by default.
Practical by design.

My projects sit at the intersection of software, data, and automation. The common thread is a question worth answering—and a tool that makes the answer useful.

Follow what I’m building ↗
01

Build the useful thing.

A developer tool that reveals a blind spot. An agent that handles the busywork. Start with a problem, not a stack.

02

Let the evidence disagree.

Keep the negative results. Compare against simple baselines. A good experiment can tell you that your idea didn’t work.

03

Make it reproducible.

Document the choices, test the assumptions, and leave enough breadcrumbs for someone else to run it.
